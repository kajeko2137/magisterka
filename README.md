# Info o implementcji
Folder implementacja na chwilę obecną zawiera pełny klon oficjalnego repozytorium sched_ext w podfolderze scx (https://github.com/sched-ext/scx), w celu łatwiejszej kompilacji całego projektu do działającego kodu. Kod napisany w ramach pracy znajduje się w folderze tls.

# Informacja o obecnym stanie kodu
W chwili obecnej część komentarzy oraz skrypty pythonowe służące jako wspomagacze została wygenerowana przez ai. Obecnie kod zawiera puste funkcje (stubs) które są potrzebne do poprawnego połączenia kodu z kernelem. Zapełnianie ich kodem faktycznego schedulera jest w trakcie.
